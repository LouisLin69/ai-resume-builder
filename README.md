# AI Resume Builder

A focused React front-end project for building, previewing, and exporting a polished resume from structured content.

## Features

- Live editor and resume preview in one screen
- Two visual templates: Studio and Technical
- Add, edit, and remove skills and project entries
- Auto-save to `localStorage`
- Export resume data as JSON
- Print or save the preview as PDF through the browser
- Responsive layout for desktop and mobile

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- LocalStorage
- Lucide React icons

## Why This Project Exists

This project is designed as a portfolio-ready front-end project for UI / front-end internship applications. It demonstrates component state management, form handling, responsive UI layout, accessible controls, print styling, and product-oriented information architecture.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
